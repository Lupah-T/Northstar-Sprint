# Test Screenshots

This directory is intended for uploading screenshots of test results.

## Instructions for Uploading

1. Save your test screenshots in this folder (`test-screenshots/`).
2. Add the files to git:
   ```bash
   git add test-screenshots/
   ```
3. Commit the changes:
   ```bash
   git commit -m "Add test screenshots"
   ```
4. Push the changes to the remote repository:
   ```bash
   git push origin main
   ```
*(Replace `main` with your current branch name if you are working on a different branch.)*
